🧬 Elementos Químicos

Conhecendo os elementos da natureza.

O que são elementos químicos?

Elementos químicos são conjuntos de átomos com o mesmo número de prótons.

Exemplos de elementos

  • Hidrogênio (H)
  • Oxigênio (O)
  • Carbono (C)
  • Ferro (Fe)
  • Ouro (Au)

Símbolos químicos

Cada elemento possui um símbolo formado por uma ou duas letras.

Exemplo:

H = Hidrogênio
O = Oxigênio
Na = Sódio
