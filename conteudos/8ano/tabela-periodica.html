🧬 Tabela Periódica

Organização dos elementos químicos.

O que é a Tabela Periódica?

A tabela periódica é uma organização dos elementos químicos de acordo com suas características.

Ela apresenta todos os elementos conhecidos pela ciência.

Como ela é organizada?

A tabela possui:

  • Períodos: linhas horizontais.
  • Famílias ou grupos: colunas verticais.
  • Símbolos dos elementos.
  • Número atômico.

Famílias importantes

  • Metais alcalinos
  • Metais alcalino-terrosos
  • Halogênios
  • Gases nobres

Exemplos de elementos

H - Hidrogênio

O - Oxigênio

C - Carbono

Fe - Ferro

Au - Ouro
