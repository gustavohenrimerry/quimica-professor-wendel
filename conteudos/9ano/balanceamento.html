⚖️ Balanceamento Químico

Equilibrando os elementos em uma reação.

O que é balanceamento químico?

É o processo de ajustar a quantidade de átomos dos reagentes e produtos para que a reação fique correta.

Lei da conservação da massa

A quantidade de átomos antes e depois da reação deve ser igual.

Os átomos não desaparecem, apenas se reorganizam.

Exemplo simples

H₂ + O₂ → H₂O

Balanceada:
2H₂ + O₂ → 2H₂O

Passos para balancear

  • Contar os átomos dos reagentes.
  • Contar os átomos dos produtos.
  • Ajustar os números da frente das fórmulas.
  • Conferir se ficou igual.
